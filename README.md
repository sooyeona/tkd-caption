# 태권 자막

태권도 수업 영상을 고르면 2~3분 하이라이트로 자동 편집하고, 분위기 자막을 넣어 저장해 주는 웹앱이에요.
서버 없이 폰 안에서 전부 처리돼서 무료이고, 영상이 어디로 업로드되지 않아요.

## 기능
- 짧은 영상 여러 개를 한 번에 골라서 이어붙이기 (순서 바꾸기·빼기 가능)
- 움직임이 많은 활동 장면 위주로 골라 30초~3분으로 자동 편집 (전체가 짧으면 자르지 않고 그대로)
- 배경음악: 앱이 직접 만드는 신나는 비트(저작권 걱정 없음) 또는 내 음악 파일, 원본 소리와 볼륨 따로 조절
- 아이 이름 자막: 이름을 넣으면 "멋진 {이름}!" → "멋진 정원이!"처럼 자동 변환 (받침 있으면 '이' 붙음)
- 수업별 자막: 줄넘기·품새·발차기 문구 따로 관리. 영상마다 수업 종류를 지정하면(전체 한 번에 지정도 가능) 그 영상 장면에 맞는 자막이 자동으로 들어가요. 파일 이름에 '줄넘기/품새/발차기'가 있으면 자동 인식
- 반 선택(유치부/초등부): 상단 태그가 "유치부 줄넘기 수업"처럼 자동으로 바뀌고, 수업이 시작되는 장면에 제목 자막이 들어가요
- 자막은 장면 단위로 바뀌고, 장면이 끝나기 직전에 사라져서 다음 장면으로 넘어가지 않아요
- 혼자 나오는 장면 + 이름 입력 → "줄넘기하는 정원이", "정원이 화이팅!" 같은 이름 자막 (수업별 + 응원형 여러 종류)
- 줄넘기·품새·발차기로 고른 영상엔 그 수업 자막만 들어가요 (공통 문구는 일반 영상용)
- 혼자/단체 자동 감지: 폰 안에서 도는 사람 인식 AI로 장면마다 한 아이가 크게 나오는지, 여럿이 나오는지 판단해서 맞는 자막을 넣어요. 문구 앞에 [혼자] / [단체]를 붙여 구분하고, 틀리면 자막 옆 👤/👥 버튼으로 바꿀 수 있어요
- 자막 스타일 3종: 예능형 / 자막바형 / 스티커형
- 폰트 6종, 글자 크기·위치 슬라이더, 장면마다 폰트 섞기(고른 폰트를 돌아가며 사용)
- 자막을 시간별로 직접 수정하거나 🎲로 하나씩 다시 뽑기
- 문구 목록 직접 추가·삭제 (폰에 저장됨)
- 상단 태그, 날짜 뱃지, 원본 소리 포함 여부
- 완성 영상은 공유 → "동영상 저장"으로 앨범에 저장

## 깃허브에 올리기 (GitHub Pages)
1. github.com 에서 새 저장소 만들기 (예: `tkd-caption`, Public)
2. **Add file → Upload files** 로 압축 푼 폴더 안의 내용을 **폴더째** 끌어다 올리기 (PC에서 하는 게 편해요)
   `index.html`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon-180.png`, `icon-512.png`, `README.md`
   `fonts.css`, `fonts/` 폴더 (글꼴 파일 7개)
   `lib/` 폴더 (tf.min.js, coco-ssd.min.js), `models/coco-ssd/` 폴더 (model.json + group1-shard 파일 5개)
   → `fonts`, `lib`, `models` 폴더 구조가 그대로 유지돼야 폰트와 혼자/단체 감지가 동작해요
3. 저장소 **Settings → Pages** → Source를 `Deploy from a branch`, Branch를 `main` / `(root)` 로 저장
4. 1~2분 뒤 `https://아이디.github.io/tkd-caption/` 주소가 생겨요

## 폰 바탕화면에 깔기 (아이폰)
1. 사파리에서 위 주소 열기
2. 아래 공유 버튼 → **홈 화면에 추가**
3. 바탕화면의 "태권 자막" 아이콘으로 앱처럼 실행

## 사용 팁
- 정밀 모드(iOS 26 이상): 프레임을 하나씩 정확히 만들어서 끊김이 없어요. 대신 완성 영상 길이의 1.5~3배 정도 걸려요. 그동안 화면을 켜두고 앱을 닫지 마세요.
- 그보다 옛날 iOS에서는 실시간 녹화 방식으로 자동 전환돼요 (폰이 바쁘면 끊길 수 있어요).
- 결과물은 최대 1280px 해상도(HD)로 저장돼요. 세로·가로 영상이 섞이면 많은 쪽 방향으로 맞추고 나머지는 검은 여백이 생겨요.
- 아주 큰 4K 영상은 느릴 수 있어요. 아이폰 카메라 설정에서 1080p로 찍으면 더 빨라요.
- 혼자/단체 감지용 AI 모델(약 18MB)은 처음 한 번만 받고 이후엔 폰에 저장돼서 바로 써요.
- 코드를 고친 뒤에는 앱을 한 번 완전히 껐다 켜면 새 버전이 반영돼요.

## 문구 기본값 바꾸기
`app.js` 맨 위 `DEFAULT_PHRASES` 목록을 고치면 돼요. (앱 안 "문구 목록"에서 고친 내용은 폰에만 저장돼요.)
